# Spec Delta

## REMOVED Requirements

### Requirement: Theme chooser
**Reason**: The theme is now chosen in Settings, under Appearance, and is kept between launches, so the top bar no longer needs a control for it.
**Migration**: Replaced by "Theme setting" in the app-settings capability.

### Requirement: Chooser accessibility
**Reason**: The chooser button no longer exists in the top bar.
**Migration**: The options in the Settings sheet carry visible text labels, as described by "Theme setting" in the app-settings capability.
